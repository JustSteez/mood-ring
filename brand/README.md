# Mood Ring brand kit

The stock market, painted once a day.

## Logo

The mark is a ring with a stone: one solid colour, no gradient. It matches the logo on the site.

| File | Use |
|---|---|
| `svg/mark-black.svg`, `png/mark-black-1024.png` | Mark on light backgrounds |
| `svg/mark-white.svg`, `png/mark-white-1024.png` | Mark on dark backgrounds or photos |
| `svg/app-icon.svg`, `png/app-icon-1024.png` | App icon / favicon (white ring on black tile) |
| `svg/lockup-black.svg`, `png/lockup-on-paper.png` | Mark + "Mood Ring" on light |
| `svg/lockup-white.svg`, `png/lockup-on-ink.png` | Mark + "Mood Ring" on dark |

Keep clear space around the logo at least the height of the stone. Don't recolour the mark with the mood colours or add gradients, outlines or shadows.

## Colours

See `png/palette.png`.

- Ink `#0A0A0A`, Muted `#6B7280`, Line `#E7E5E4`, Paper `#FAFAF9`
- Moods (art only): Euphoric `#D4FF3A`, Bullish `#B8F5D2`, Flat / Genesis `#5B2EFF`, Bearish `#FF8A3D`, Panic `#FF3B30`

## Type

Inter (free, Google Fonts). Bold/Extra Bold for headlines with slightly tight letter spacing, Regular/Medium for body.
